راهنمای استفاده
مسیر پیشنهادی برای کار روزمره با مخزن آفلاین و آنلاین.
۱. تنظیم امن
ابتدا در تب نمای کلی دانلود را خاموش نگه دارید و زمان‌بندی مرکزی یا مستقل هر لیست را تنظیم کنید.
۲. ساخت لیست
در بخش لیست‌ها جست‌وجو و دسته‌بندی کنید، چند صفحه را ورق بزنید و موارد انتخابی را به یک لیست اضافه کنید.
۳. مدیریت کاتالوگ
در تب کاتالوگ با جست‌وجو، دسته، نوع و وضعیت فعال فیلتر کنید؛ ستون انتخاب برای تغییر گروهی و نقطهٔ وضعیت برای تغییر تکی است.
۴. نصب آفلاین
پروژه را با npmrc به رجیستری محلی وصل کنید. اگر بسته در cache نبود و اینترنت در دسترس باشد، نصب آفلاین خطا می‌دهد و باید ابتدا آنلاین Sync کنید.
حالت اتصال رجیستری
این دستورها از ریشهٔ پروژه اجرا می‌شوند. دکمهٔ کپی فقط متن را در Clipboard می‌گذارد؛ اجرای آن را آگاهانه انجام دهید.
آنلاین — دریافت metadata و package
اتصال به npmjs فعال می‌شود و Verdaccio موارد موجود در cache را نگه می‌دارد.
docker compose up -d
آفلاین سخت — فقط cache محلی
هیچ uplink اینترنتی وجود ندارد؛ مناسب زمان قطع اینترنت.
docker compose -f compose.yaml -f compose.offline.yaml up -d
خاموش‌کردن سرویس‌ها
Containerها متوقف می‌شوند اما volume و cache باقی می‌ماند.
docker compose down
